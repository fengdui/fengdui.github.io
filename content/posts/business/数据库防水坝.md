# 运维管控
账号授权：账号托管 免密登录  
访问授权：又分为数据操作授权和快速授权  
数据操作授权 分为数据授权 和 数据库对象操作  
## 数据授权 即通过敏感资产集合授权
该模块主要实现对敏感数据（已分类分级资产）的查询（select）：结果明文、结果脱敏、更新（update）、插入（insert）、删除（delete）、数据复制（select_data）等权限的授权以及行数控制的权限设置。以资产集合为最小粒度，授权权限模板到每个访问身份/身份组/属性身份。  
当数据库添加并选择运维管控能力后，资产模块会自动生成默认资产集合组以及1、2、3、4级敏感资产集合。访问授权模块同样会做资产集合的展示。当身份模块添加具体运维身份后，会触发初始化授权逻辑，每个资产集合都会增加基于身份组的授权，基于不同的敏感资产级别关联不同的权限模板。  
- 一级敏感资产集合授权“数据只读”模板：包含查询结果明文、禁止插入、更新、删除、数据复制。  
- 二级、三级、四级及以上敏感资产集合授权“数据只读且脱敏”模版：包含数据查询脱敏、禁止插入、更新、删除、数据复制。  
  数据库对象操作 即授权一些dcl 此模块对数据库各种实体（例如表、视图、存储过程、函数等）进行管理和操作的权限，这些权限包括DDL（数据定义语言）和DCL（数据控制语言）操作权限。  
## 快速授权
权限模板 数据表操作 数据库操作 数据库账号操作 代码操作 数据库授权操作  
- 基于表：可对数据表操作进行授权，包含：包含查询(SELECT)、更新(UPDATE)、插入(INSERT）、删除（DELETE）、复制(SELECT_DATA)、清空表数据（TRUNCATE TABLE）、修改表格（ALTER TABLE）、删除表格（DROP TABLE）。  
- 基于schema：可对schema下的数据表操作和代码操作进行授权，具体操作可以查看权限模板。  
- 基于库：可以对数据库内的数据表操作、数据库操作、数据库账号操作、代码操作、数据库授权操作进行授权。具体操作可以查看权限模板。  


# 审计
日志 在定义的资产类型（包括数据库、应用及终端）被连接或访问时，所执行的操作行为，包括但不限于登录、访问、数据读取、修改、删除等。  

安全事件 从资产、身份、风险等级和发生时间等四个维度，对同类型的告警事件进行聚合，形成一个完整的安全事件。  
将审计日志中的告警事件和风险规则与模型监测到告警事件，对同访问主体、访问客体、访问行为和告警类型的事件进行合并后查看，进行统一集中管理  
告警事件  
当日志信息触发预设的风险规则时，系统将该事件标记为告警事件。

# 安全防御模块
安全防御主要实现对撞库、恶意扫描、误操作、假冒业务应用等场景的防护。具体功能包括防口令暴破、僵尸账号处置、超时登出、防扫描、误操作恢复、应用防假冒。  
- 防口令暴破：防止黑客较短的时间内尝试大量的用户名和密码组合，以找到正确的组合来获取对数据库的访问权限  
- 僵尸账号处置：支持对已经废弃但仍然存在于系统中的账号进行梳理和锁定  
- 超时登出：支持对登录数据库后一定时间不操作的连接，设置自动断连  
- 防扫描：防止黑客或恶意用户对数据库进行扫描、侦查和探测，以发现潜在的安全漏洞和攻击目标。  
- 误操作恢复：支持对误删除后的数据进行数据恢复。注：仅支持敏感表数据的恢复  
- 应用防假冒：防止通过假冒业务应用程序来获取数据库的访问权限  
- 防脱库
## 防扫描
仅拦截数据库初始握手事件（扫描工具通常在此时探测版本信息）非oracle CONNECT,mysql MYSQL_GREETING, sqlserver SQLSERVER_PRELOGIN 直接跳过  
Oracle数据库：版本查询与TNS漏洞扫描 扫描工具（如Nessus）常通过 VERSION 命令查询Oracle版本，或利用 service_register_NSGR 触发TNS服务注册漏洞。scancheck 模块检测这些命令并返回伪造拒绝响应  
MySQL数据库：版本字符串探测 扫描工具通过MySQL握手包（MySQLGreeting）的版本字符串识别数据库版本（如 8.0.30）。scancheck 模块替换真实版本为配置的伪装版本（如 m_mysql_80_ver_），隐藏漏洞特征：  
SQL Server数据库：版本字段篡改 扫描工具通过 SqlServerPrelogin 事件的版本字段识别SQL Server版本。scancheck 模块修改版本号为配置的伪装值（m_sqlserver_ver_），避免暴露真实版本漏洞  
防扫描场景 = 全局开关启用（m_active_=1） + 当前时间在[startTime, endTime]窗口内 + 事件类型为初始握手事件（OracleConnect/MySQLGreeting/SqlServerPrelogin） + 数据库ID在保护列表中（m_set_dbid_sptr_包含dbid） + 协议特征匹配扫描行为（版本查询/TNS漏洞/版本字符串探测）
