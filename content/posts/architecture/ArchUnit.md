ArchUnit 是一个为 Java 项目提供架构测试的工具。它让你能够像写单元测试一样，为你的代码架构编写“单元测试”  
保团队遵守架构规范，或者发现现有的代码依赖关系开始失控，ArchUnit 会是一个非常有价值的选择  
专门用于架构合规性检查，表达能力更强 随着项目规模增长，代码架构很容易腐化。虽然我们可以通过文档约定架构规范，但人工审查难免遗漏，且难以持续。ArchUnit 把架构规则变成了可执行的测试代码，并集成在持续集成（CI）流程中。一旦有人违反了规则（比如本该在 Service 层调用 Repository 的代码，直接调用了 Web 层的类），测试就会失败，从而在早期发现并阻止架构退化
