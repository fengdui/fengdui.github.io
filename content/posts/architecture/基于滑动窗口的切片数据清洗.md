- **时间维度（Time）**：数据的时间属性，支持多粒度时间窗口
- **业务维度（Business）**：业务实体标识，如用户、交易、设备等
- **指标维度（Metrics）**：计算指标类型，如计数、求和、平均值等


任意数据点可用三维坐标定位：
```
坐标 = (时间窗口, 业务实体, 指标类型)
示例 = (2023-12-01_1000, user:12345, transaction_amount)
```

系统采用固定时间窗口进行数据分片：

```java
// 时间窗口计算算法
public class TimeWindow {
    public static String getWindowKey(long timestamp, int windowSizeSeconds) {
        long windowStart = (timestamp / 1000 / windowSizeSeconds) * windowSizeSeconds;
        return formatTimestamp(windowStart);
    }
}
```

支持不同粒度的时间窗口：

| 窗口类型 | 窗口大小 | 用途 | TTL |
|---------|---------|------|-----|
| 秒级窗口 | 1-10秒 | 实时监控 | 1小时 |
| 分钟窗口 | 1-5分钟 | 短期统计 | 1天 |
| 小时窗口 | 1小时 | 趋势分析 | 30天 |
| 天级窗口 | 1天 | 历史分析 | 1年 |

### 时间窗口Key结构

```
完整Key = 业务Key + 时间窗口标识
示例：
- user:12345:20231201_1000  (用户在10:00分钟窗口的数据)
- txn:T001:20231201_10     (交易在10点小时窗口的数据)
- device:D001:20231201     (设备在当天的数据)
```


```
数据输入 → 分类队列 → 批量合并 → 时间窗口聚合 → 立方存储 → 查询服务
```


### 数据合并策略

```java
public class BatchMergeProcessor {
    public void processBatch(List<DataRecord> batch) {
        // 1. 按Key分组
        Map<String, List<DataRecord>> keyGroups = groupByKey(batch);
        
        // 2. 按时间窗口再分组
        Map<String, List<DataRecord>> windowGroups = groupByTimeWindow(keyGroups);
        
        // 3. 执行合并计算
        Map<String, MergedData> results = new HashMap<>();
        for (Entry<String, List<DataRecord>> group : windowGroups.entrySet()) {
            String windowKey = group.getKey();
            List<DataRecord> records = group.getValue();
            
            MergedData merged = mergeRecords(records);
            results.put(windowKey, merged);
        }
        
        // 4. 批量写入存储
        batchWriteToStorage(results);
    }
}
```

### 多维查询接口

```java
@Path("/query")
public class QueryService {
    
    @POST
    @Produces("application/json")
    public JSONObject query(QueryRequest request) {
        // 解析查询维度
        TimeRange timeRange = request.getTimeRange();
        List<String> businessKeys = request.getBusinessKeys();
        List<String> metrics = request.getMetrics();
        
        // 多维度查询执行
        return executeMultiDimensionalQuery(timeRange, businessKeys, metrics);
    }
    
    private JSONObject executeMultiDimensionalQuery(
            TimeRange timeRange, 
            List<String> businessKeys, 
            List<String> metrics) {
        
        // 1. 生成时间窗口列表
        List<String> timeWindows = generateTimeWindows(timeRange);
        
        // 2. 构造查询Key列表
        List<String> queryKeys = new ArrayList<>();
        for (String timeWindow : timeWindows) {
            for (String businessKey : businessKeys) {
                queryKeys.add(businessKey + ":" + timeWindow);
            }
        }
        
        // 3. 批量查询数据
        Map<String, CubeData> cubeData = batchQuery(queryKeys);
        
        // 4. 按指标维度聚合
        return aggregateByMetrics(cubeData, metrics);
    }
}

具体怎么做合并呢 都继承Mergeable基类
比如平均值这样 接受应该Mergeable类合并该类得到一个新的Mergeable
将细节封装起来

```
package cn.com.bsfit.frms.obj;

/**
 * 平均数类，用于计算和维护数值的平均值
 */
public class AvgNumber extends MergeableNumber {
    
    private static final long serialVersionUID = 1L;
    
    /**
     * 默认构造函数
     */
    public AvgNumber() {
        super();
    }
    
    /**
     * 使用数值构造
     * @param value 数值
     */
    public AvgNumber(Number value) {
        super(value);
    }
    
    /**
     * 使用数值和计数构造
     * @param value 数值
     * @param count 计数
     */
    public AvgNumber(Number value, long count) {
        super(value, count);
    }
    
    /**
     * 合并另一个可合并对象
     * @param other 另一个可合并对象
     * @return 合并后的对象
     */
    @Override
    public Mergeable merge(Mergeable other) {
        if (!(other instanceof AvgNumber)) {
            return this;
        }
        
        AvgNumber otherAvg = (AvgNumber) other;
        
        // 计算新的平均值：(this.value * this.count + other.value * other.count) / (this.count + other.count)
        double newValue = (this.doubleValue() * this.getCount() + otherAvg.doubleValue() * otherAvg.getCount()) 
                         / (this.getCount() + otherAvg.getCount());
        
        this.setValue(newValue);
        this.setCount(this.getCount() + otherAvg.getCount());
        this.setMerged(true);
        
        return this;
    }
    
    /**
     * 快速克隆
     * @return 克隆的对象
     */
    @Override
    public Cloneable fastClone() {
        AvgNumber cloned = new AvgNumber(this.getValue(), this.getCount());
        cloned.setMerged(this.isMerged());
        return cloned;
    }
}
