Bridge 模式（桥接模式）  
Docker 在主机上创建一个虚拟网桥（默认名为 docker0），每个容器会连接到这个网桥，并分配一个独立的 IP 地址 就像主机是一个路由器（网桥），所有容器是连接在这个路由器上的独立设备  
连接到同一个桥接网络的容器可以通过 IP 地址或容器名相互通信  
容器可以通过主机的 NAT（网络地址转换）访问外网  
外部无法访问容器内的服务。必须通过 -p 参数将容器的端口映射到主机的端口上  

Host 模式（主机模式）  
容器直接使用主机的网络命名空间，不进行任何网络隔离。容器共享主机的 IP 地址和端口  
就像主机上的两个普通进程一样通信 直接使用主机的网络 容器内监听的端口直接绑定在主机上，无需 -p 映射  

公司的网关使用了docker模式部署 用户可以通过后端页面推送docker镜像镜像  
因此通过后端部署的时候提供桥接模式和主机模式两种模式  
当用户选择桥接模式的时候 需要生成2个端口 一个是容器内的端口 一个是容器外部转发端口即主机的端口 网关容器启动使用容器内端口监听0.0.0.0 给用户的访问链接或者透明代理的是容器外部的端口  
主机模式只需要生成一个端口
