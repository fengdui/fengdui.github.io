通过将中缀表达式（我们常见的数学表达式形式）转换为后缀表达式来简化公式的计算过程。后缀表达式的优势在于不需要考虑运算符优先级和括号，可以直接通过栈结构进行计算。  
系统定义了一个抽象基类 FormulaUnit，各种公式元素都是它的子类：
- NumCons: 数字常量
- Constant: 常量
- Operator: 运算符 (+, -, *, /)
- BracketPair: 括号对
- Fraction: 分数
- SuperScript: 上下标
- NthRoot: 根式
- GetMax/GetMin: 最大值/最小值函数
- IndiUnit: 指标单元
- CardUnit: 评分卡单元
- MatrixUnit: 矩阵单元
  FormulaUtils 工具类
  这是处理公式的核心工具类，主要包含以下方法： 
- 转换过程
   中缀转后缀 (preOrder2PostOrder)  
   将中缀表达式转换为后缀表达式：  
   1.遍历中缀表达式的每个元素  
   2.如果是数字或常量，直接输出到后缀表达式队列  
   3.如果是运算符，根据优先级决定是否将栈顶运算符弹出到输出队列  
   4.如果是左括号，压入栈中  
   5.如果是右括号，将栈中元素弹出直到遇到左括号  
   6.遍历完成后，将栈中剩余运算符全部弹出到输出队列  
   运算符优先级处理  
   在 Operator 类中定义了优先级比较方法：
```
public boolean notLessThan(Operator operator) {
    // 乘除法优先级高于加减法
    if (FormulaConstants.PLUS.equals(value) || FormulaConstants.MINUS.equals(value)) {
        if (FormulaConstants.PLUS.equals(operator.getValue()) || FormulaConstants.MINUS.equals(operator.getValue())) {
            return true;
        }
    } else {
        return true;
    }
    return false;
}
```
公式生成  
   后缀表达式计算 (genFunction)  
   1.创建一个空栈  
   2.从左到右扫描后缀表达式  
   3.如果是操作数（数字、常量、指标等），压入栈中  
   4.如果是运算符，从栈中弹出两个操作数，进行运算后将结果压回栈中  
   5.最终栈中剩下的唯一元素就是计算结果  
实际应用示例  
   假设我们要处理表达式 (3 + 4) * 5：  
   1.解析阶段: 前端将表达式解析为JSON对象数组  
   2.中缀转后缀:  
- 输入: [(, 3, +, 4, ), *, 5]  
- 输出: [3, 4, +, 5, *]  
  3.生成函数表达式:  
- 扫描到 3，入栈: [3]  
- 扫描到 4，入栈: [3, 4]  
- 扫描到 +，弹出 4 和 3，计算 3+4=7，入栈: [7]  
- 扫描到 5，入栈: [7, 5]  
- 扫描到 ，弹出 5 和 7，计算 75=35，入栈: [35]  
- 结果: 35  
复杂公式支持  
   系统还支持更复杂的公式元素：  
- 分数: 分子分母分别转换为后缀表达式  
- 函数调用: 如 getMax, getMin 等  
- 嵌套结构: 括号内的表达式递归处理
