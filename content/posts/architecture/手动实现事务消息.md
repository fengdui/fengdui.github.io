发出消息保证事务提交 事务回滚消息不提交 事务没提交消息不可见

事务里面先做业务操作 生成发送的消息 记录到表里面 因为在一个事物 保证消息一定有记录  
即使发送失败了 也可以根据消息记录做重发  
然后是消息具体发送 如果事务还没提交 先使用如下方法记录同步器 等到事务提交之后在发出消息  
避免下游没反查到数据 因为事务还没提交就发消息就会出现这样的情况  

```
public static void executeAfterCommit(Runnable action) {
    if (TransactionSynchronizationManager.isSynchronizationActive()) {
        TransactionSynchronizationManager.registerSynchronization(new TransactionSynchronization() {

            @Override
            public void afterCommit() {
                action.run();
            }
        });
    } else {
        action.run();
    }
}
```
发出消息之后变更消息记录的状态为已发送  
下游业务做好幂等
