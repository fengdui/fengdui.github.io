DBSCAN算法  
初始化：将所有数据点标记为“未访问”。  
步骤2遍历与判断： 从未访问点中任选一点 p，标记其为“已访问”。 检查其 ε-邻域（半径为ε的圆形区域）内的点数。  
步骤3核心点判定与簇扩张： 如果 p 的ε-邻域内点数 ≥ MinPts，则 p 为核心点： 以 p 为起点创建新簇。  
将其ε-邻域内所有点加入一个“待考察集合”（种子集），开始链式扩张： 从集合中取一点 q，若 q 未访问，则标记为已访问。  
若 q 自身也是核心点（其ε-邻域内点数 ≥ MinPts），则将其邻域内未在集合中的点也加入集合，确保扩张能持续。  
若 q 不属于任何已有簇，则将其归入当前簇。  
重复此过程，直到“待考察集合”为空，当前簇停止生长。  
如果 p 的ε-邻域内点数 < MinPts，则 p 被暂时标记为噪声（后续可能被其他核心点吸收为边界点）。  
循环与结束： 重复步骤2-3，直到所有点都被访问。 最终，所有点被划分为若干个簇（由核心点和边界点组成）和噪声点。  

```
DBSCAN(D, eps, minPts):
    label all points in D as unvisited
    cluster_id = 0
    
    for each point p in D:
        if p is visited:
            continue
        mark p as visited
        N = region_query(p, eps)
        
        if |N| < minPts:
            mark p as noise
        else:
            cluster_id += 1
            expand_cluster(p, N, cluster_id, eps, minPts)

expand_cluster(p, N, cluster_id, eps, minPts):
    assign p to cluster_id
    S = N  # seed set
    
    for each q in S:
        if q is unvisited:
            mark q as visited
            N_q = region_query(q, eps)
            if |N_q| >= minPts:
                S = S ∪ N_q
        if q has no cluster assignment:
            assign q to cluster_id

region_query(p, eps):
    return all points within distance eps from p (including p)
```
