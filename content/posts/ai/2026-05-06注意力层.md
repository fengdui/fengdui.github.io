输入 -> [注意力子层 -> Add & Norm] -> [前馈网络子层 -> Add & Norm] -> 输出  
每个输入词首先被转换成向量（词嵌入），并加上位置编码（告诉模型这个词的位置信息）。这个组合向量可以看作是第0层的“初始隐藏状态”。  
多层编码器中的迭代 这个初始状态被送入第一个编码器层。该层的核心操作就是自注意力。  
在这一层内，每个词的初始向量会与本句子中所有其他词的初始向量（即同一层的输入）进行交互、比较，计算出新的、包含了上下文信息的向量。这个过程就是“自”——自己看自己。  
这个新向量再经过一个前馈神经网络，最终输出成为第一个编码器层的隐藏状态输出。   
第一个编码器层输出的隐藏状态 H₁，作为输入，被送入第二个编码器层。 第二层同样进行自注意力计算，但此时每个词向量已经包含了第一层整合过的上下文信息。因此，这次“自看自”是在更高级的语义层面上进行的，能捕捉更复杂的关系。 如此反复，经过多个（例如6层或12层）编码器层的处理，最终的隐藏状态 HN 是经过多层上下文信息反复整合、精炼后的结果，包含了整个句子最全面、最深层的表示  


scaled dot-product attention 缩放点积注意力  
输入的向量 X 比如是 [我， 爱， 人工智能]   Q = X * W^Q  假设向量维度是512  
得到Q矩阵由所有词的查询向量（q_我, q_爱, q_人工智能）堆叠而成。它的每一行代表一个词的“查询向量”  
然后会做拆分 也就是多头注意力的多头  
分割到各个头（从512维到64维） 接下来，这个512维的 q_爱_full 被均匀地分割成8份，每份64维。  
这8份分别成为8个头的输入： q1_爱 (64维) 给头1 q2_爱 (64维) 给头2 ... 以此类推。 这是维度从512变为64的唯一地方。这种分割是结构化的，不是随机的  
各头在64维子空间内独立工作（关键步骤） 对于头1，它现在拥有： q1_爱 (64维) k1_我, k1_爱, k1_人工智能 (都是64维，由完整K矩阵以同样方式分割而来) v1_我, v1_爱, v1_人工智能 (都是64维，由完整V矩阵以同样方式分割而来) 头1的所有计算（点积、Softmax、加权求和）都严格在64维的空间内进行。它不需要、也无法看到其他头的65-512维信息。 q1_爱 只会和同样来自头1的 k1_我、k1_爱、k1_人工智能 做点积  
Q*K 做点积之后得到的是a*a的矩阵 这里的a就是token数量 这里就是3 这个矩阵就是注意力权重矩阵  
对于句子 [我， 爱， 人工智能]，假设是第2行（对应“爱”）：  
第2行第1列 S[2][1]：是 q_爱 与 k_我 的点积，衡量 “爱”与“我”的相关性。  
第2行第2列 S[2][2]：是 q_爱 与 k_爱 的点积，衡量 “爱”与自身的相关性。  
第2行第3列 S[2][3]：是 q_爱 与 k_人工智能 的点积，衡量 “爱”与“人工智能” 的相关性。  
这一整行，就定义了“爱”这个词的原始关注视野  
Softmax归一化：对该行所有分数进行Softmax操作，将其转化为一个概率分布（所有权重为正且和为1）。这个概率分布就是最终的 “注意力权重”。它决定了在聚合信息时，每个位置的“值”v_j能分到多少“话语权”。  
比如第二行爱的归一化结果是 注意力权重 A[“爱”] = [0.1, 0.8, 0.1]  
加权求和：用这行归一化后的权重，对所有位置的值向量 v_j 进行加权求和，生成当前位置 i 的新表示。这个过程就是“上下文信息聚合”  
上面的爱的新的向量就是0.1*v_我+0.8*v_爱+0.1*v_人工智能  
到这里还是多头 上面的例子v也是分割了8个64维度 那么33的矩阵 和V(3*64) 最后得到3*64的矩阵  
然后将多个头的数据融合 变成3*512维度 和初始向量X一样维度的新的向量  
比如  
输入: [我是, 中国, 人]  
输出: [包含"中国"和"人"信息的"我是"表示,  
包含"我是"和"人"信息的"中国"表示,  
包含"我是"和"中国"信息的"人"表示]  
整个注意力层 W_Q W_K W_V这几个是我们要学习的参数 保存在模型文件（如 .pt 或 .bin 文件）  
Q W K是使用上面3个每次临时生成的  
然后进行残差连接（图中的虚线）和层归一化（LayerNorm）操作 最终进入Position-wise Feed-Forward Network 位置感知的前馈网络 FFN  
输入矩阵 X (3个词，每个词是d_model维向量):  
[ [向量_I],  
[向量_am],  
[向量_good] ]  

经过变换得到三个矩阵:  
Q = X * W^Q = [ [q_I],   [q_am],   [q_good] ]   (3 x d_k)  
K = X * W^K = [ [k_I],   [k_am],   [k_good] ]   (3 x d_k)  
V = X * W^V = [ [v_I],   [v_am],   [v_good] ]   (3 x d_v)  

关键计算步骤:  
1. Q * K^T: 这是一个 (3 x d_k) 矩阵 乘以 (d_k x 3) 矩阵，得到一个 (3 x 3) 的“注意力分数矩阵”。  
   这个矩阵的每一行代表一个“查询词”与所有“键词”的关联度。  
   例如，第一行是：q_I 与 k_I、k_am、k_good 的点积结果。  

   输出分数矩阵 S (3x3):  
   [ [s(q_I, k_I),   s(q_I, k_am),   s(q_I, k_good)],  
   [s(q_am, k_I),  s(q_am, k_am),  s(q_am, k_good)],  
   [s(q_good, k_I), s(q_good, k_am), s(q_good, k_good)] ]  

2. 对 S 的每一行做 softmax，得到注意力权重矩阵 A (3x3)。  

3. A * V: (3x3) 矩阵 乘以 (3 x d_v) 矩阵，得到最终的输出矩阵 (3 x d_v)。  
   这个输出矩阵的每一行，已经是原始词向量融合了序列中所有词信息后的新表示。  


Attention = Softmax((Q · K^T) / √d_k) · V
