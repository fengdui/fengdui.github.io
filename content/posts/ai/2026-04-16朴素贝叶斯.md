贝叶斯公式  
P(c∣x)=P(c)⋅P(x∣c) /P(x)  

P(c)：先验概率。表示在没有见到任何样本特征时，类别 c 出现的概率  
P(x∣c)：似然概率。表示在已知类别为 c 的条件下，观察到特征组合 x 的概率。  
P(x)：证据因子。表示在所有类别下观察到特征 x 的边缘概率。  
P(c∣x)：后验概率。表示在观察到特征 x 后，样本属于类别 c 的概率。  

我们希望找到使后验概率 P(c∣x) 最大的类别 c  

分母P(x) 只是一个正的缩放常数，不影响最大值的位置 所以我们求P(c)⋅P(x∣c)最大化的c  
朴素贝叶斯的核心假设（条件独立性假设）： 假设在给定类别 c 的条件下，所有特征  x 1  ,x 2  ,...,x n  两两相互独立。  
基于此假设，联合似然概率可以分解为各个特征条件概率的乘积：  P(x∣c)=P(x 1  ,x 2  ,...,x n  ∣c)= i=∏ P(x i  ∣c)  

最大的类别 c  
对于每个类别 c， 计算该类别的先验概率 P(c)。 对于样本的每一个特征 x i  ，计算在类别 c 下出现该特征值的概率 P(x i  ∣c)。  
将所有特征的条件概率 连乘，再乘以先验概率。 选择使这个乘积值最大的类别 c 作为预测结果  
在实际计算中，由于多个概率（通常都是小于1的小数）连续相乘，会导致结果极其接近0，造成数值下溢。  
解决方案：对公式取对数。因为对数函数 log(⋅) 是单调递增函数，取对数后不会改变最大值点。

公式中的 P(c) 和 P(x i  ∣c) 需要从训练数据集 D 中估计  
对于离散特征，如果某个特征值在训练集的某个类别中从未出现，会导致P(xi∣c)=0，从而使整个后验概率为0。为避免此问题，使用拉普拉斯平滑（加1平滑）
