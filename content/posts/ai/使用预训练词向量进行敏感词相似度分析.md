使用词向量取平均值进行sentence embedding得到句向量
```
private float[] sumVector(List<float[]> vectorValues) {
    if (vectorValues.isEmpty()) {
        return null;
    } else {
        int num = ((float[])vectorValues.get(0)).length;
        float[] res = new float[num];
        int size = vectorValues.size();

        for(float[] vectorValue : vectorValues) {
            for(int i = 0; i < num; ++i) {
                res[i] += vectorValue[i];
            }
        }

        for(int i = 0; i < num; ++i) {
            res[i] /= (float)size;
        }

        return res;
    }
}
```
然后对于需要识别的敏感词也做如上操作得到句向量
在和业务类型的句向量进行余弦相似度分析
```
public static float squaredCosineSimilarity(float[] vector1, float[] vector2) {
    Objects.requireNonNull(vector1, "向量1不能为null");
    Objects.requireNonNull(vector2, "向量2不能为null");
    int length1 = vector1.length;
    int length2 = vector2.length;
    if (length1 != length2) {
        throw new IllegalArgumentException(String.format("向量坐标数不相等 %s, %s", length1, length2));
    } else {
        float molecular = 0.0F;
        float sourceDenominator = 0.0F;
        float targetDenominator = 0.0F;

        for(int i = 0; i < length1; ++i) {
            molecular += vector1[i] * vector2[i];
            sourceDenominator += vector1[i] * vector1[i];
            targetDenominator += vector2[i] * vector2[i];
        }

        float denominator = sourceDenominator * targetDenominator;
        return molecular * molecular / denominator;
    }
}
```
